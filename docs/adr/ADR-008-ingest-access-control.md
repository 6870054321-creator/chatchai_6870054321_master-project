# ADR-008: การควบคุมการเข้าถึง Link Ingest API

- **สถานะ:** Proposed — รอการตัดสินใจในขั้นตอน 7.5
- **วันที่:** –
- **ผู้ตัดสินใจ:** ผู้วิจัย (ทบทวนกับอาจารย์ที่ปรึกษา)

## บริบท
ระบบสำหรับสมาชิกผูกบัญชีกับเลขบ่งชี้บริษัทแบบหนึ่งต่อหนึ่งอยู่แล้ว ขอบเขตงานไม่พัฒนาการแยกข้อมูลระหว่างสมาชิก

## ทางเลือกที่พิจารณา
1. โทเค็นเดียวสำหรับระบบเดิม (Bearer token)
2. แยกเครือข่าย (ไม่เปิดเส้นทาง /api สู่ภายนอก)
3. mTLS ระหว่างระบบ
4. โทเค็นต่อสมาชิก + ตรวจเลขบ่งชี้บริษัท

## พฤติกรรมของต้นแบบในปัจจุบัน (ชั่วคราว)
ต้นแบบใช้ Bearer token เดียว (`INGEST_TOKEN`) ถ้าไม่ตั้งค่า API จะปิด แบบเดียวกับ Resolver CE ที่ใช้ `SESSION_TOKEN`

unit test `access control`
