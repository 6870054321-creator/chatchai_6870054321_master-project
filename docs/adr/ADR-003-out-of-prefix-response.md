# ADR-003: คำตอบสำหรับตัวระบุนอกช่วงเลขบ่งชี้บริษัท (T-11)

- **สถานะ:** Proposed — รอการตัดสินใจในขั้นตอน 7.5
- **วันที่:** –
- **ผู้ตัดสินใจ:** ผู้วิจัย (ทบทวนกับอาจารย์ที่ปรึกษา)

## บริบท
ตัวระบุที่ถูกต้องตามไวยากรณ์แต่ไม่ได้อยู่ในช่วงที่สถาบันรับผิดชอบ

## ทางเลือกที่พิจารณา
1. 404 Not Found
2. 400 Bad Request
3. เปลี่ยนเส้นทางไปยังรีโซลเวอร์ระดับโลก (id.gs1.org)

## พฤติกรรมของต้นแบบในปัจจุบัน (ชั่วคราว)
ต้นแบบตอบ 404 (`src/pipeline/validator.js`)

## หลักฐานที่ใช้ตัดสินใจ
T-11 กับทั้งสามระบบ

## การตัดสินใจ
_(ยังไม่ตัดสินใจ — ระบุทางเลือกที่เลือกและข้อกำหนดของมาตรฐานที่อ้างอิง)_

## ผลที่ตามมา
_(ข้อดี ข้อเสีย และสิ่งที่ต้องทำต่อ)_
