# ADR-009: การย้อนกลับจากระดับตัวขยายกุญแจไปยังระดับ GTIN

- **สถานะ:** Proposed — รอการตัดสินใจในขั้นตอน 7.5
- **วันที่:** –
- **ผู้ตัดสินใจ:** ผู้วิจัย (ทบทวนกับอาจารย์ที่ปรึกษา)

## บริบท
คำขอ `/01/{gtin}/10/{lot}` ที่ไม่มีชุดลิงก์ระดับรุ่นการผลิต

## ทางเลือกที่พิจารณา
1. ย้อนไปใช้ชุดลิงก์ระดับ GTIN
2. ตอบ 404
3. ย้อนกลับเฉพาะบางประเภทลิงก์

## พฤติกรรมของต้นแบบในปัจจุบัน (ชั่วคราว)
ต้นแบบย้อนกลับทีละระดับจนถึงระดับ GTIN (`src/pipeline/linksetResolver.js`)

## หลักฐานที่ใช้ตัดสินใจ
T-08 และกรณีเสริมที่ใช้ lot ที่ไม่มีข้อมูล

## การตัดสินใจ
_(ยังไม่ตัดสินใจ — ระบุทางเลือกที่เลือกและข้อกำหนดของมาตรฐานที่อ้างอิง)_

## ผลที่ตามมา
_(ข้อดี ข้อเสีย และสิ่งที่ต้องทำต่อ)_
