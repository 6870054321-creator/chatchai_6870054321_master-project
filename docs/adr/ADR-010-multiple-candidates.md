# ADR-010: เมื่อการต่อรองเนื้อหายังเหลือลิงก์มากกว่าหนึ่งรายการ

- **สถานะ:** Proposed — รอการตัดสินใจในขั้นตอน 7.5
- **วันที่:** –
- **ผู้ตัดสินใจ:** ผู้วิจัย (ทบทวนกับอาจารย์ที่ปรึกษา)

## บริบท
Resolver CE ตอบ 300 Multiple Choices เมื่อเหลือหลายรายการ (`web_logic.py` `_handle_link_type`) ต้องทดสอบว่าเบราว์เซอร์ของผู้บริโภคที่สแกนสัญลักษณ์จะถูกนำไปยังหน้าใดหรือไม่ เมื่อได้คำตอบ 300

## ทางเลือกที่พิจารณา
1. เลือกหนึ่งรายการตามลำดับที่ลงทะเบียน แล้วเปลี่ยนเส้นทาง
2. ตอบ 300 พร้อมรายการลิงก์
3. ตอบชุดลิงก์ 200

## พฤติกรรมของต้นแบบในปัจจุบัน (ชั่วคราว)
ต้นแบบเลือกหนึ่งรายการ: ชนิดสื่อก่อน แล้วภาษา แล้วลำดับที่ลงทะเบียน (`src/pipeline/contentNegotiator.js`)

## หลักฐานที่ใช้ตัดสินใจ
T-01 เมื่อไม่ส่ง Accept-Language เทียบระหว่างต้นแบบกับ Resolver CE

## การตัดสินใจ
_(ยังไม่ตัดสินใจ — ระบุทางเลือกที่เลือกและข้อกำหนดของมาตรฐานที่อ้างอิง)_
