# ADR-004: การตีความ `Accept: application/json`

- **สถานะ:** Proposed — รอการตัดสินใจในขั้นตอน 7.5
- **วันที่:** –
- **ผู้ตัดสินใจ:** ผู้วิจัย (ทบทวนกับอาจารย์ที่ปรึกษา)

## บริบท
ผู้เรียกบางรายขอ JSON ทั่วไปโดยไม่ระบุ `application/linkset+json`

## ทางเลือกที่พิจารณา
1. ถือว่าขอชุดลิงก์
2. ถือว่าขอข้อมูล JSON-LD ของผลิตภัณฑ์
3. ตอบ 406 Not Acceptable

## พฤติกรรมของต้นแบบในปัจจุบัน (ชั่วคราว)
ต้นแบบถือว่าขอชุดลิงก์ (`src/pipeline/linksetResolver.js`)

## หลักฐานที่ใช้ตัดสินใจ
T-05, T-06 และกรณีเสริมที่ส่ง `Accept: application/json`

## การตัดสินใจ
_(ยังไม่ตัดสินใจ — ระบุทางเลือกที่เลือกและข้อกำหนดของมาตรฐานที่อ้างอิง)_

## ผลที่ตามมา
_(ข้อดี ข้อเสีย และสิ่งที่ต้องทำต่อ)_
