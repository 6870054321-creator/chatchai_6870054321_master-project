# ADR-007: วิธีนำข้อมูลลิงก์จากระบบสำหรับสมาชิกเข้าสู่ที่จัดเก็บ

- **สถานะ:** Proposed — รอการตัดสินใจในขั้นตอน 7.5
- **วันที่:** –
- **ผู้ตัดสินใจ:** ผู้วิจัย (ทบทวนกับอาจารย์ที่ปรึกษา)

## บริบท
ขอบเขตงานไม่แก้ไขระบบสำหรับสมาชิก แต่รูป 4.2 มีเส้น Register link ไปยัง Link Ingest API

## ทางเลือกที่พิจารณา
1. ระบบสำหรับสมาชิกเรียก Link Ingest API (push)
2. ดึงข้อมูลเป็นรอบจากฐานข้อมูลเดิม (sync)
3. ผู้ดูแลนำเข้าเป็นชุด (batch import)

## พฤติกรรมของต้นแบบในปัจจุบัน (ชั่วคราว)
ต้นแบบมี Link Ingest API แบบ PUT ต่อหนึ่งตัวระบุ (`src/ingest/ingestApi.js`) ซึ่งใช้ได้ทั้งแบบ push และเป็นปลายทางของตัวดึงข้อมูลแบบ sync

## หลักฐานที่ใช้ตัดสินใจ
จำนวนครั้งที่ต้องแก้ระบบเดิม, ความล่าช้าของข้อมูล, การปฏิเสธข้อมูลผิดตั้งแต่ตอนลงทะเบียน

## การตัดสินใจ
_(ยังไม่ตัดสินใจ — ระบุทางเลือกที่เลือกและข้อกำหนดของมาตรฐานที่อ้างอิง)_
