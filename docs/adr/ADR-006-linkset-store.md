# ADR-006: เทคโนโลยีของที่จัดเก็บชุดลิงก์

- **สถานะ:** Proposed — รอการตัดสินใจในขั้นตอน 7.5
- **วันที่:** –
- **ผู้ตัดสินใจ:** ผู้วิจัย (ทบทวนกับอาจารย์ที่ปรึกษา)

## บริบท
เส้นทางอ่านต้องพร้อมใช้งานสูง ส่วนการปรับปรุงลิงก์ยอมให้ปรากฏช้าได้เล็กน้อย (ใช้กรอบ PACELC อธิบาย)

## ทางเลือกที่พิจารณา
1. แฟ้ม JSON โหลดเข้าหน่วยความจำ
2. Redis
3. MongoDB (แบบ Resolver CE)
4. PostgreSQL JSONB

## พฤติกรรมของต้นแบบในปัจจุบัน (ชั่วคราว)
ต้นแบบใช้แฟ้ม JSON ในหน่วยความจำผ่านส่วนต่อประสาน `get/put/delete` (`src/store/linksetStore.js`) จึงเปลี่ยนเทคโนโลยีได้โดยไม่แก้ท่อประมวลผล

## หลักฐานที่ใช้ตัดสินใจ
P50/P95 ที่ 10,000 และ 100,000 ลิงก์ (`tests/bench.js`), เวลาเริ่มระบบ, หน่วยความจำ

## การตัดสินใจ
_(ยังไม่ตัดสินใจ — ระบุทางเลือกที่เลือกและข้อกำหนดของมาตรฐานที่อ้างอิง)_
