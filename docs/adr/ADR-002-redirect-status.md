# ADR-002: รหัสสถานะสำหรับการเปลี่ยนเส้นทาง

- **สถานะ:** Proposed — รอการตัดสินใจในขั้นตอน 7.5
- **วันที่:** –
- **ผู้ตัดสินใจ:** ผู้วิจัย (ทบทวนกับอาจารย์ที่ปรึกษา)

## บริบท
ระบบปัจจุบันตอบ 302 ส่วน Resolver CE ตอบ 307 เมื่อเหลือลิงก์เดียว (`web_logic.py` `_handle_link_type`)

## ทางเลือกที่พิจารณา
1. 302 Found
2. 307 Temporary Redirect
3. 308 Permanent Redirect / 301

## พฤติกรรมของต้นแบบในปัจจุบัน (ชั่วคราว)
ต้นแบบใช้ 307 ตั้งค่าได้ที่ `REDIRECT_STATUS`

## หลักฐานที่ใช้ตัดสินใจ
T-01, T-03, T-06–T-08 รันซ้ำด้วย REDIRECT_STATUS=302 และ 307 แล้วเทียบกับข้อกำหนดของมาตรฐาน

## การตัดสินใจ
_(ยังไม่ตัดสินใจ — ระบุทางเลือกที่เลือกและข้อกำหนดของมาตรฐานที่อ้างอิง)_

## ผลที่ตามมา
_(ข้อดี ข้อเสีย และสิ่งที่ต้องทำต่อ)_
